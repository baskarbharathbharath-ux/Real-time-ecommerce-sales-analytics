# 🛒 Real-Time E-Commerce Sales Analytics

### Sales Monitoring | Business Intelligence | Data Analytics

## 📌 Project Overview

The **Real-Time E-Commerce Sales Analytics** project demonstrates how simulated live sales data can be generated using Python, stored in Oracle Database, analyzed using SQL, and visualized through Power BI.

The project helps monitor sales performance, order trends, product revenue, payment methods, customer activity, and order cancellations through an interactive dashboard.

## 🎯 Project Objectives

- Simulate incoming e-commerce orders at regular intervals.
- Store sales transactions in Oracle Database.
- Perform data analysis using SQL queries.
- Build an interactive Power BI dashboard.
- Monitor important business KPIs.
- Generate actionable business recommendations.

## 📊 Dataset Description

The project uses a synthetic e-commerce dataset generated by Python.

| Column | Description |
|---|---|
| Order ID | Unique order identifier |
| Order Timestamp | Date and time of the order |
| Customer ID | Customer identifier |
| Product Name | Name of the purchased product |
| Category | Product category |
| Quantity | Number of units ordered |
| Unit Price | Price per unit |
| Discount Percentage | Discount applied |
| Net Amount | Order amount after discount |
| Payment Method | UPI, Card, COD, etc. |
| City | Customer city |
| Order Status | Completed, Processing, or Cancelled |

**Note:** The data is simulated for learning and portfolio demonstration. It is not sourced from a live e-commerce platform.

## ▶️ How to Run the Project

### 1. Clone the repository

```bash
git clone https://github.com/YOUR-USERNAME/real-time-ecommerce-sales-analytics.git
cd real-time-ecommerce-sales-analytics
```

Replace `YOUR-USERNAME` with your GitHub username.

### 2. Install dependencies

```bash
python -m venv .venv
```

Activate the virtual environment and install the required packages:

```bash
pip install -r requirements.txt
```

### 3. Configure Oracle Database

- Execute `sql/01_create_tables.sql`.
- Copy `.env.example` to `.env`.
- Enter your Oracle connection credentials in `.env`.
- Test the connection using:

```bash
python python/test_connection.py
```

### 4. Generate simulated sales data

```bash
python python/simulate_sales.py
```

The script inserts new simulated orders into Oracle Database at regular intervals. Press `Ctrl+C` to stop the process.

### 5. Execute SQL analysis

Run the following scripts in Oracle SQL Developer:

- `sql/02_dashboard_views.sql`
- `sql/03_analysis_queries.sql`

### 6. Build the Power BI dashboard

Connect Power BI Desktop to Oracle Database, load the relevant table or reporting views, create the required measures, and build the dashboard visuals.

Refresh the report to retrieve new data. Dashboard update frequency depends on the selected connection mode and refresh configuration.
